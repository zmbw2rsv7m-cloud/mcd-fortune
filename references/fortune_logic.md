# 求签逻辑

求签 = 「签等 → 时段 → 真实菜单」三方映射，保证可下单。

## 1. 定时辰
`now-time-info` 小时：早 5–10 / 午 10–14 / 下午茶 14–17 / 晚 17–21 / 夜宵 21–5。

## 2. 定签等
时段主权重 + 轻微随机抖动（±1 档，偶发±2）。用户附心愿仅轻度偏移（求顺/事业 +1，累/想躺 −0~1；无心愿仅用基准+抖动）。

| 时段 | 签等基准 |
|---|---|
| 早 | 中~上 |
| 午 | 上~上上 |
| 下午茶 | 中~上 |
| 晚 | 上~上上 |
| 夜宵 | 中~下 |

## 3. 签等 → 餐品（命定餐品）
从 `query-meals` 实时菜单模糊匹配（不写死）。每签等定 1 个 `productCode`：

| 签等 | 基调 | 餐品倾向 |
|---|---|---|
| 上上 | 犒赏丰盛 | 双牛/豪华套餐/加蛋加芝士 |
| 上 | 顺稳 | 巨无霸/板烧鸡腿堡 |
| 中 | 平常心 | 麦辣鸡腿堡/堡+小食 |
| 下 | 轻省 | 随心配/吉士蛋堡/玉米杯 |
| 下下 | 先吃饱再战 | 基础堡+热饮 |

券后价：第 5 步 `auto-bind-coupons` 领的券 `couponId` 带入 `calculate-price` 的 `items[].couponId`；不适用则原价。

## 4. 签诗生成（梗必须当季，不写死）
- 核心流程第 2 步已用 `WebSearch "<年><月> 网络热梗 流行语"` 取到 2-3 个当季梗（干饭/摸鱼/躺平/省钱类）。
- 按签等**基调**写 4-8 句半文半梗签诗，把梗自然揉进去；梗要新鲜，不复用旧梗。
- **搜索不可用**：退回通用俏皮话兜底（如「今日宜干饭，忌假装不饿」「先吃饱，再扛」），**绝不编造梗名**。
- 开发者彩蛋（仅当用户明显是程序员）：可加一句 Git/代码梗。

结构示范（非写死，仅示意）：「【<签等>】<一句庙签开场>。<揉入热梗的一句>。宜<…>、忌<…>。」

## 5. 今日宜/忌
主框架按签等稳定（下表），可把当日热梗之一作彩蛋揉进 1 条：

| 签等 | 宜 | 忌 |
|---|---|---|
| 上上 | 聚餐、加蛋、犒劳自己、拍照 | 将就、饿着开会、说「随便吃点」 |
| 上 | 干饭、摸鱼式休息、加可乐 | 边吃边回消息、假装不饿 |
| 中 | 细嚼慢咽、小确幸、准点吃 | 狼吞虎咽、拖到饿晕 |
| 下 | 省、随心配、轻装 | 冲动加购、被满减套路 |
| 下下 | 吃饱、躺平五分钟、热饮暖胃 | 空腹硬扛、省那一口 |

## 6. 麦门提醒
第 5 步已 `auto-bind-coupons` 自动领券（免费），卡里注「已领 N 张」；`available-coupons`（无参）取可领券 markdown 直接呈现 1-3 条；`campaign-calendar` 提示活动/临期券。⚠️ `query-promotions` 仅团餐(beType=6)专用，默认不调。
