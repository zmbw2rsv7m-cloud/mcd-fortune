# 输出样例（sample_output）

> 「麦门赛博求签」签文卡渲染形态示例，真实字段以 MCP 返回为准；展示已换算的「元」价（换算逻辑见 SKILL「响应解析」，不写入本卡）。签诗应融入当季热梗。

```
🏮 麦门赛博求签 · <日期> <周几> · <时段>时辰
📍 庙址：<外送门店名>（麦乐送外送）
🏠 送餐至：<城市·区>（地址已脱敏，完整门牌不展示）

━━━ 签 🔻 ━━━
【<签等>】<签诗一两句>
今日宜<…>、宜<…>、宜<…>；忌<…>、忌<…>。

━━━ 命定餐品 🍔 ━━━
已为你领 <N> 张麦麦省券（如：<券名> 等）

· 到店自取版
  <餐品名> ×1
  到店价 ¥<到手价>（含可用券优惠）
  门店：<到店门店名>

· 麦乐送外送版
  <餐品名> ×1
  外送到手 ¥<到手价>（含运费/打包费 + 可用券优惠）
  送餐：<外送门店名>

━━━ 麦门提醒 🔔 ━━━
（来自 available-coupons，返回 markdown 文本，直接呈现，不解析 JSON）
### 麦麦省优惠券列表：
- 优惠券标题：<券名> ｜ 状态：<已领取/可领取>

━━━ 求签结果 ━━━
说「就按这个下单」，我帮你确认后下单（到店或外送任选）。
（默认不自动下单）
```

## 安全下单确认态（用户说「就按这个下单」后）

```
🧾 待确认订单（<外送/到店>）
餐品：<餐品名> ×1
门店：<门店名>
取餐方式：<麦乐送 / 到店自取>
到手：¥<到手价>（原价 ¥<原价>，已用券 ¥<优惠>）

（未确认不会下单，绝不静默扣费）
```
